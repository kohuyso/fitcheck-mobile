# TanStack Query & OpenAPI Integration Skill

This skill documents architectural patterns for API integration, server state management, query key centralization, and type safety using `@hey-api/openapi-ts` and `@tanstack/react-query`.

## 1. OpenAPI SDK & Generated Types
- OpenAPI SDK functions are located in `@/api/sdk.gen.ts`.
- Schema types MUST be imported directly from `@/api/types.gen.ts`.
- Never write manually duplicated interface definitions for backend entities; always import generated types:
  ```typescript
  import type { ItemRead, OutfitRead, UserRead, CalendarEventRead } from '@/api/types.gen';
  ```
- When backend API contracts change, regenerate the client via:
  ```bash
  npm run generate-api
  ```

## 2. API Axios Client & Token Storage (`src/api/axios.ts`, `src/api/storage.ts`)
- All API requests flow through the custom Axios instance configured in `src/api/axios.ts`.
- Base URL dynamically resolves the host Metro server IP for device and Android emulator (`10.0.2.2:8000` / Local IP).
- Request interceptor automatically retrieves and attaches the Bearer auth token stored via `expo-secure-store` helpers in `src/api/storage.ts`.

## 3. Centralized Query Keys Factory (`src/api/query-keys.ts`)
Always import and use centralized query keys from `@/api/query-keys.ts` to ensure consistent cache invalidation across all screens (`closet`, `calendar`, `outfit-detail`, `explore`):

```typescript
import { itemKeys, outfitKeys, eventKeys, userKeys } from '@/api/query-keys';

// Example query usage
export function useClosetItems(category?: string) {
  return useQuery({
    queryKey: itemKeys.list({ category }),
    queryFn: async () => {
      const response = await getItemsApiV1ItemsGet({ query: { category } });
      return response.data;
    },
    staleTime: 1000 * 60 * 5, // 5 mins
  });
}
```

## 4. Mutation & Cross-Screen Cache Synchronization

When mutating data (deleting an outfit, deleting an item, scheduling/deleting a calendar event), invalidate all relevant query keys so other screens update seamlessly without requiring a hard refresh:

```typescript
import { useMutation, useQueryClient } from '@tanstack/react-query';
import { outfitKeys, eventKeys, itemKeys } from '@/api/query-keys';

export function useDeleteOutfit() {
  const queryClient = useQueryClient();

  return useMutation({
    mutationFn: async (outfitId: string) => {
      await deleteOutfitApiV1OutfitsOutfitIdDelete({ path: { outfit_id: outfitId } });
    },
    onSuccess: () => {
      // Invalidate outfits, closet, and calendar events caches simultaneously
      queryClient.invalidateQueries({ queryKey: outfitKeys.all });
      queryClient.invalidateQueries({ queryKey: eventKeys.all });
      queryClient.invalidateQueries({ queryKey: itemKeys.all });
    },
  });
}
```

## 5. Optimistic Updates & Cache Rollback
For instant tap feedback, update local TanStack Query cache optimistically and roll back on error:

```typescript
export function useDeleteItem() {
  const queryClient = useQueryClient();

  return useMutation({
    mutationFn: async (itemId: string) => {
      await deleteItemApiV1ItemsItemIdDelete({ path: { item_id: itemId } });
    },
    onMutate: async (itemId) => {
      await queryClient.cancelQueries({ queryKey: itemKeys.all });
      const previousItems = queryClient.getQueryData(itemKeys.lists());

      queryClient.setQueryData(itemKeys.lists(), (old: any) =>
        Array.isArray(old) ? old.filter((item: any) => item.id !== itemId) : old
      );

      return { previousItems };
    },
    onError: (err, itemId, context) => {
      if (context?.previousItems) {
        queryClient.setQueryData(itemKeys.lists(), context.previousItems);
      }
    },
    onSettled: () => {
      queryClient.invalidateQueries({ queryKey: itemKeys.all });
    },
  });
}
```

## 6. Defensive Error & Loading States
- Component data hooks must return explicit `isLoading` / `isPending`, `isError`, and `data` states.
- Always check for array nullability (`items?.map(...) ?? []`) to prevent runtime crashes when backend returns empty array or null properties.
